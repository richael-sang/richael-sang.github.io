# Rui Sang

Source for [richael-sang.github.io](https://richael-sang.github.io), a Jekyll-based
technical and research portfolio focused on computer vision, multimodal learning,
vision-language models, and robust machine learning.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

The site preserves the structure and attribution of the
[academic-homepage](https://github.com/luost26/academic-homepage) template.
